RD3 Tech Lead Engine - Operations Manual

This manual covers setup, architecture, and maintenance for the RD3 Tech lead processing system.

1. System Architecture Overview

ComponentFile / LocationRole
Frontend Webservercontact.phpCaptures web form data, sanitizes fields, and posts JSON payload via cURL.
Script BackendMain.gs + modulesProcesses anti-spam rules, tags keywords, updates Google Sheets, and sends emails.
DatabaseGoogle Sheet ("Leads")Stores structured records of all leads, status flags, and timestamps.
Taxonomy EditorAdminUI.htmlVisual GUI accessed via ?page=admin to modify repair keywords.

2. Installation & Deployment Steps

  1. Open Google Sheets and click Extensions > Apps Script.
  2. Create all 7 .gs files and 3 .html files as defined in the project codebase.
  3. Click Deploy > New deployment.
  4. Select type Web App. Set Execute as: Me and Who has access: Anyone.
  5. Copy the generated Web App URL.
  6. Open contact.php on your web server and replace $webAppUrl with your URL.

3. Managing Keywords (Taxonomy)

Admin Editor Access: Append ?page=admin to your deployed Web App URL:
https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec?page=admin

Use the visual tree editor to add or remove categories and keywords. Click Save Taxonomy when finished. Changes apply instantly without requiring re-deployment.

4. Debugging and Testing

To verify the pipeline directly within Apps Script:

  • Select Tests.gs in the editor file menu.
  • Choose testLeadPipeline from the function dropdown and click Run.
  • Check the Execution log for confirmation output.
