RD3 Tech — Contact Form System Maintenance Guide

This document explains how to modify, update, and manage the RD3 Tech contact form backend and email auto-responder system.

⚠️ IMPORTANT: Whenever you modify Code.gs or HTML files, you MUST create a NEW WEB APP VERSION under "Deploy -> Manage Deployments" for the changes to go live on your WordPress site!

1. File Structure Overview

  • Code.gs — Primary Google Apps Script backend engine (processes POST requests, checks spam, writes to Google Sheets, and sends emails).
  • ClientTemplate.html — The branded HTML email template sent automatically to the customer upon form submission.
  • AdminTemplate.html — The internal notification email template sent to ADMIN_EMAIL with full enquiry details.
  • HOW_TO_MODIFY.html — This documentation file.

2. How to Change Admin Notification Recipients

Open Code.gs and edit line 7 at the top of the file:

var ADMIN_EMAIL = "tom@rd3tech.com";

To send notifications to multiple staff members, separate emails with commas:

var ADMIN_EMAIL = "tom@rd3tech.com, support@rd3tech.com";

3. Modifying Email Templates

Option A: Via Google Apps Script Files (Default)

  • Edit ClientTemplate.html to change the customer confirmation design or wording.
  • Edit AdminTemplate.html to change how submission details are displayed to the admin team.
  • Variables like <?= name ?> and <?= situation ?> are dynamically replaced with submitted form data during execution.

Option B: Dynamic Override via Google Sheet (Optional)

If your Google Sheet contains a tab named EmailTemplates, the system will read subject lines and body text directly from there instead of the HTML files:

  • Row A2: Key AdminSubject | Value {FLAG_PREFIX}New Inquiry: {NAME}
  • Row A3: Key AdminBody | Value HTML content or plain text...
  • Row A4: Key ClientSubject | Value We received your request — RD3 Tech
  • Row A5: Key ClientBody | Value HTML content or plain text...

4. Adding or Managing Flagged Keywords

To automatically flag incoming enquiries containing specific keywords (e.g., promotional terms, high-priority issues, or competitors):

  1. Create or open the Settings tab in your linked Google Sheet.
  2. Add target keywords in Column A, starting at cell A2 down.
  3. Submissions matching any of these terms will trigger a yellow review banner in the Admin Email notification.

5. WordPress Shortcode Adjustments

The form is rendered in WordPress via shortcode [rd3_contact_form].

  • To change form questions or selection drop-downs, edit the HTML inside your WordPress snippet or plugin file.
  • Ensure input field id attributes match the JavaScript formData.append(...) payload keys in the shortcode script.
  • Honeypot field: Must remain named hp_website to preserve invisible spam filtering.

6. How to Deploy Code Updates Live

  1. In Apps Script, click Save (Ctrl + S / Cmd + S).
  2. Click Deploy (top right blue button) → Manage deployments.
  3. Click the Pencil icon (Edit) next to the active Web App deployment.
  4. Click the Version drop-down menu and select New version.
  5. Click Deploy.

7. Troubleshooting Checklist

  • Client email not arriving? Check if the submission filled the hidden hp_website field (causes isSpam = true, suppressing client confirmation).
  • Script errors? Select function testClientEmailNow at the top toolbar in Code.gs and click Run to view real-time error messages in the editor console log.
